# MotionCapture Studio（单文件 Web 版）

基于浏览器的**视频动作捕捉工具**：上传一段人物视频，AI 自动识别人体骨骼关键点，驱动 3D 数字模特实时复现动作，并可导出动作记录与 720P 视频。

整个应用是**一个 HTML 文件**（约 88KB），无需安装、无需服务器，双击即可运行。

## ✨ 功能特性

- **视频动作捕捉**：导入 MP4/WebM/MOV 视频，自动检测人体 33 个骨骼关键点
- **多人场景支持**：一帧检测到多个人体时，点击画面中的方框选择追踪目标；追踪采用髋部最近邻匹配 + 指数平滑，抗抖动、丢失自动恢复
- **AI 双引擎**：主引擎 MediaPipe PoseLandmarker（BlazePose Heavy，GPU 加速，原生多人检测）；旧版 Pose 引擎自动兜底，加载稳定可靠
- **程序化 3D 模特**：纯代码生成的精致人形模特（无外部 3D 资源），男女两套默认体型
- **37 项身形参数**：身高、肩宽、臂长、腿围等细节可调，支持左右对称锁定，打造自定义模特
- **动作记录管理**：录制结束自动保存；支持导出/导入 JSON 记录文件
- **多视频修正融合**：对同一动作录制多段视频，加权融合提升动作精度
- **回放系统**：播放 / 暂停 / 进度拖拽 / 0.5x–2x 变速
- **720P 视频导出**：以 60fps 导出 WebM 格式动作视频（VP9，自动回退 VP8）
- **3D 自由视角**：鼠标拖拽旋转、滚轮缩放（OrbitControls）

## 🚀 快速开始

### 方式一：直接运行

下载 `MotionCapture-Studio.html`，用 Chrome / Edge 浏览器打开即可。

### 方式二：GitHub Pages 在线运行

1. 将文件重命名为 `index.html` 并推送到仓库
2. 仓库 **Settings → Pages → Source** 选择 `main` 分支
3. 访问 `https://<用户名>.github.io/<仓库名>/`

## 📖 使用流程

1. **等待引擎加载**：首次打开需加载 AI 检测引擎（约 10–40 秒，视网络情况）
2. **导入视频**：点击「导入视频」，系统自动对多个采样帧做人形检测
   - 单人视频：自动锁定目标（绿色方框）
   - 多人视频：点击画面中对应方框，选择要追踪的人
3. **开始捕捉**：点击「播放」，左侧视频播放，右侧模特实时同步运动并记录关键帧
4. **自动保存**：播放结束（或手动停止）后，动作记录自动保存，视频自动弹出
5. **回放 / 导出**：回放检查效果，可导出 JSON 记录或 720P WebM 视频
6. **（可选）修正融合**：导入另一段同动作视频进行加权融合，提升精度

### 拍摄建议

- 人物**全身入镜**，占画面高度 1/3 以上
- 光线充足，背景尽量简洁
- 相机固定（不要大幅移动镜头）
- 视频编码建议 H.264 的 MP4（HEVC/H.265 部分浏览器无法解码）

## 🛠 技术栈

| 模块 | 技术 |
|---|---|
| 3D 渲染 | Three.js r128 + OrbitControls（CDN） |
| 姿态估计 | MediaPipe Tasks Vision（PoseLandmarker Heavy）/ 旧版 Pose 兜底 |
| 关键点 | 33 个 BlazePose 归一化关键点，时间轴线性平插值 |
| 姿态映射 | 层级骨骼四元数求解（父系补偿 + SLERP 平滑） |
| 视频导出 | Canvas `captureStream(60)` + `MediaRecorder`（VP9/VP8，8Mbps） |
| 界面 | 原生 HTML/CSS/JS，零构建、零依赖安装 |
